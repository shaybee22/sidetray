Invite someone

An invite link opens Side Tray with this server and group filled in; they only type their name and email. It grants nothing by itself: you still approve them here after the phone call.

Send the link by message or email, or let them scan the code. Side Tray has to be installed first.

Join requests

For each request, phone the person and have them read you their code. Type what you hear. The app only approves it if it matches.
